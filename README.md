## Regenerating

From this directory:

```sh
groovy types-gen.groovy ../ ./src/types
```

Walks `../` recursively, picks up every enum under `chat.subscribers.*`,
writes one JSON file per enum into `src/types/`. Add a new enum anywhere in
the monorepo, rerun, file appears.
